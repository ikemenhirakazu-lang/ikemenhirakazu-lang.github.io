## 「バカは5000円が好き」はどういう意味か？

SNSで最も広まったのが、この「**バカは5000円が好き**」という言葉です。

ユーチュラなどが報じた内容によると、これは**店にかかってくる電話**について語った場面で出てきます。電話の多くが「**今日、5,000円で彫ってほしい**」という内容だった、という話です。

そこから「**バカは5000円が好き**」という言い方につながりました。

同じ動画では、客を「**99%バカ**」と表現し、「**民度がとても低い**」とも語ったと報じられています。具体的には、**予約の3件に1件がすっぽかし**で、**礼儀のある客は1%**、という内容でした。

冒頭では、タトゥーを入れている人への世間の偏見（怖い・頭が悪そう・不良っぽい）を挙げたうえで、「**だいたい合っている**」と述べています。

一方で「**1%はちゃんとした人**」とも言い、ミュージシャンやスポーツ選手を例に挙げていました。

同氏のチャンネルでもこの件を取り上げていて、そちらは**35万2,775回**再生。高須クリニックの高須幹弥さんも取り上げ、**35万7,544回**再生されています。

Xでは「バカは5000円が好き」がミーム化し、車や買い物など、タトゥーとは関係のない消費行動を語る文脈でも使われるようになりました。

## バズる前は何をしていたチャンネルだったのか？

同じチャンネルの過去の動画をさかのぼると、内容は<strong>タトゥーの話ではありませんでした</strong>。中心にあったのは、人生論とお金の話です。

再生数も**2万〜11万回**が中心でした。

以下も、本人が付けた動画のタイトルです。

| タイトル | 再生数 |
|---|---|
| 働いても金持ちにも幸せにもなれないよ？ | 11万3,000回 |
| 幸せになりたいなら地味で有能な女と付き合え | 10万8,000回 |
| その仕事、今すぐ辞めていいよ | 8万4,000回 |
| 消えたい | 5万6,000回 |
| 20代で何者にもなれなかった人へ | 3万9,000回 |
| YouTube辞めるんで最後に僕と会ってください | 2万3,000回 |

「YouTube辞めるんで最後に僕と会ってください」が**2万3,000回**、「消えたい」が**5万6,000回**。この並びを見ると、伸び悩んでいた時期があったことがうかがえます。

そこに8月3日の**252万7,281回**が来ました。2万〜11万回が中心だったチャンネルに、いきなり252万回です。

この6本のうちいちばん再生数の少ない「YouTube辞めるんで最後に僕と会ってください」（2万3,000回）と比べると、**約110倍**。いちばん多い「働いても金持ちにも幸せにもなれないよ？」（11万3,000回）と比べても、**約22倍**になります。

8月14日の動画タイトルにある「運でバズった」という自己評価は、この落差を踏まえると読み方が変わってきます。
