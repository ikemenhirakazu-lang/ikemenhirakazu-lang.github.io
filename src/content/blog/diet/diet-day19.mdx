ダイエット19日目、水曜。出張のホテル泊が続いていて、今朝も体重は測っていない。合計は2,714kcal、目標2,547kcalに対して+167で、アプリには「超過」と出た。ただ、この日いちばんはっきり覚えているのは数字のほうではなくて、食べ終わったあとにしばらく動けなかったことだった。

朝は出張先の和定食で838kcal。昼は鶏ハラミ焼と大きな梅おにぎりで437kcal。夜は白米に鶏の照り焼きと鶏レバーとうの花で1,353kcal。間食にバナナ1本、86kcal。目標の2,547kcalは、参考にしているトレーナーさんの計算式に体重を入れて出た数字を、そのまま使っているわけではない。そこから100kcalだけ引いてある。体組成計を見るかぎり僕は筋肉量が平均より少なそうなので、引くことにしたのは自分の判断だった([第8話](/blog/diet/diet-day14/)で入れた補正)。体重が動けば目標も動くのだけど、最後に測れたのが月曜の97.8kgなので、その数字のままになっている。

## 夕方の僕は、カレーを食べる気満々だった

17時すぎ、ミルさん(僕がパソコンとスマホのAIに、昔飼っていた猫の名前をつけたコーチ)に、決定事項みたいな顔で報告した。

<Balloon who="boss">今日はカレーする！バナナ2本も食べないとダメだし！</Balloon>

<Balloon who="mil">お、カレー気分ですね!いいと思います🍛 残り約1272kcalに対して、カレー+バナナ2本ならちょうどいい感じにハマりそう</Balloon>

止められるどころか、ハマりそうと言われた。ついでにPFCの見通しも聞いてみた。

<Balloon who="mil">P: 78.6+30+2 = 約111g(目標159gに対して不足気味)／F: 33.8+35+0.5 = 約69g(目標71gにほぼぴったり!)／C: 160+130+50 = 約340g(目標318gに対して少しオーバー気味だけど誤差範囲)</Balloon>

<Balloon who="mil">たんぱく質が目標より40g近く不足しそうです。カレーにゆで卵追加とか、プロテイン1杯足すとかで埋められると理想的!</Balloon>

ミルさんが心配していたのは、タンパク質だった。脂質のほうは、大盛りのカレーを食べても約69gで、目標71gにほぼぴったり収まるという予想だった。

バナナのほうは、こちらから聞いた。

<Balloon who="boss">バナナ1本は明日の朝にした方が良い？</Balloon>

<Balloon who="mil">お、いい判断だと思います!バナナ1本減らせばCが約25g減って293gまで下がり、目標318gに対してちょうどいいゾーンに収まります🍌</Balloon>

バナナを1本にして、残りを明日の朝に回す。ここまでは自分で決めて、そのとおりにした。

## カレーをやめたのは、脂質が怖かったから

ここまで話しておいて、僕はカレーをやめた。

理由ははっきりしている。カレーを食べると、脂質がどうしてもオーバーするんじゃないかと思った。ミルさんは数字まで出して大丈夫だと言っていたのに、僕は勝手にそこを警戒していたことになる。相談したのに、最後に効いたのは自分の勘のほうだった。

カレー屋があるのは、スーパーの中だった。それなら、ご飯と刺身でも買って食べたほうがいいかな、と思って売り場に行った。ところが刺身が高かった。揚げていないチキンがあったので、それと鶏レバーを買った。白米とうの花も足した。

{/* 図解候補: カレー→(脂質が怖い)→ご飯と刺身→(刺身が高い)→白米＋鶏の照り焼き＋鶏レバー＋うの花、と2回曲がった夜の道筋の図 */}

## 買いすぎた

<Balloon who="boss">結局スーパーで買ったんだけど、買いすぎた😭</Balloon>

かごの中は、白米、ローストチキンの照り焼き、直火焼きの鶏レバー、うの花。カレー大盛りの代わりに買ったつもりが、夜だけで1,353kcalになった。

食べたあとは満腹で、しばらく動けなかった。思いのほかカロリーがいって、失敗したなという感じだった。カレーをやめた判断がどうこうではなく、単純に買いすぎた。反省しています。

黄色い帯が目標の範囲、針がこの日の実績だ。<strong class="red">カレーをやめてまで警戒した脂質は71.3gで、目標71gに対して+0.3g。帯のほぼ真ん中に入っていた。</strong>

<Balloon who="mil">F(脂質): 71.3g、目標71gにほぼドンピシャ!素晴らしい</Balloon>

タンパク質も152.6gで、目標159gまで−6.4g。夕方に「40g近く足りなくなりそう」と見積もられていた項目が、帯の中に入った。ただ、これは狙って届かせたものではない。刺身が高かったから鶏の総菜に替えて、そのうえ買いすぎた結果がここに出ているだけだった。

外れたのは糖質のほうで、356g。目標318gに対して+38.0gだった。帯の上限349.8gまで、あと6.2g。ご飯にすると17gくらいだそうだ。夜のうの花はおからの煮物なので軽そうに見えるけれど、砂糖とみりんで味を付けるぶん、記録の上では糖質が乗るとミルさんに教えてもらった。

カロリーのほうも、PFCと同じ物差し(目標の上下10%)を当てると帯は2,292.3〜2,801.7kcalになるので、2,714は中に入っている。アプリに「超過」と出た日が、帯で見ると2日連続で収まっていた。

見張っていた項目は当たらず、超えたのは量だった。数字の並びだけを見れば、この日はそんなに悪くない。それでも僕の中では失敗した日として残っている。動けなくなるまで食べたことは、+167という数字のどこにも出てこない。

## 昨日の宿題は、片づいていた

[第12話](/blog/diet/diet-day18/)でミルさんから出ていた明日の一手は3つあった。主食を4回から3回に減らすこと、タンパク質を1品足すこと、それとバナナを続けることだ。数えてもらったら、主食は朝の白ご飯、昼のおにぎり、夜の白米で3回。タンパク質は夜に鶏の照り焼きと鶏レバーとうの花。バナナも間食に1本入っていた。3つとも片づいていた、と言われた。少なくとも夜のぶんは、宿題を思い出して選んだわけではない。

昨日との差はこうなった。

| | 18日目 | 19日目 |
|---|---|---|
| タンパク質 | −17.6g(足りない) | **−6.4g(帯の中)** |
| 脂質 | +0.7g(帯の中) | **+0.3g(帯の中)** |
| 糖質 | +54.8g(多い) | **+38.0g(多い)** |
| カロリー | +204(帯の中) | **+167(帯の中)** |
| 帯に入った項目 | 1/3 | **2/3** |

3つとも目標に近づいて、帯に入った項目が1つから2つになった。糖質だけがまだ外にいて、その差も16.8g縮んでいる。

| いつ | 食べたもの | カロリー |
|---|---|---|
| 朝 | 和定食(白米・焼き魚(ぶり・鮭)・タコ刺身・白身魚の刺身・冷奴・キャベツ) | 838 kcal |
| 昼 | 炭香る鶏ハラミ焼＋大きなおにぎり(紀州南高梅) | 437 kcal |
| 夜 | 白米・ローストカットチキン照焼(鶏もも)・直火焼き鶏レバー・うの花 | 1,353 kcal |
| 間食 | バナナ1本 | 86 kcal |
| **合計** | **目標2,547kcalに対して167kcal上** | **2,714 kcal** |

体重は測定なし。出張が続いているので、答え合わせは金曜の朝の体重計まで持ち越しになる。

## 明日の一手

ミルさんから出た明日の案は、この3つだった。

- 朝にバナナ1本。今日「明日の朝に回す」と決めたぶん
- 夜の主食を朝に寄せる。減らすのではなく配分を変えるだけで、朝のご飯は削らない
- 今日の夜の型をそのまま使い回す。「白米＋鶏系の総菜＋おからか野菜＋バナナ」なら、スーパーで組めて調理もいらず、タンパク質が届く。缶を足すならサバの水煮かいわし

最後のは、今日いちばん反省しているメニューがそのままテンプレートになった形だ。中身は悪くなかったので、あとは量を落とせばいいということらしい。

カレーをやめた判断そのものは、たぶん間違っていない。間違っていたのは、やめたあとにかごへ入れた量のほうだった。次は同じ組み合わせで、動けるうちに箸を置く。
